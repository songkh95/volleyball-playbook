# 지금 있는 기능

시작 계획(2026-08-25)의 0~6단계는 대부분 들어갔다. 그 위에 3D 보기, 경기 기록, 선수 자세, 공 높이·비행이 추가됐다.

## 홈

- 전술 프로젝트(앨범) 만들기, 이름 바꾸기, 삭제
- 앨범 안에 전술 여러 개
- 전술 복제, 이름 변경, 커버 사진
- 대형 프리셋: 앱 기본 대형 + 사용자가 만든 대형
- 백업 저장(`.vpb`) / 백업 불러오기(목록에 추가 또는 전부 교체)

## 에디터 — 코트

- 하프코트(우리 9m + 상대 3m = 12m) 또는 풀코트(18m × 9m)
- 좌표는 코트 기준 0~1. 하프↔풀 전환 시 타임라인은 초기화(확인 후)
- 선수, 공, 콘, 텍스트
- 선수 무제한. 추가·삭제는 **모든 장면**에 같은 id로 반영
- 우리팀(기본 빨강 `#FF3B3B`) / 상대팀(기본 파랑 `#3B8BFF`)

## 에디터 — 장면(컷)

- 장면 추가·삭제(최소 1개), 드래그로 순서 변경, 이름 변경
- 타임라인 슬라이더로 장면 사이 위치 보간
- 재생, 반복, 배속
- 이동 궤적: 선수 유니폼색, 공 노랑

## 에디터 — 보기 모드

| 모드 | 하는 일 |
|---|---|
| 전술모드 | 2D에서 선수·공 배치, 선택·드래그 |
| 영역 | 선수 책임 범위(원), 공 낙하 부채꼴 |
| 3D 보기 | 같은 장면을 3D 코트로. 카메라 코너 프리셋 |
| 마킹모드 | 화살표·실선·점선 펜, 지우개, 레이저. 선은 그 장면에만, 보간 없음 |

## 선수 자세 (2D 배지 + 3D 모델)

선수 편집에서 고른다. 공 높이가 자동으로 고르지 않는다.

| 자세 | 2D | 3D |
|---|---|---|
| 대기 | 배지 없음 | 원기둥 (idle GLB 아직 없음) |
| 리시브 | 리 | `player-receive.glb`. 공이 가까우면 손 플랫폼 위로 |
| 토스 | 토 | 아직 원기둥 (`player-set.glb` 없음) |
| 스파이크 | 스 | `player-spike.glb`. 타격 컷에서 손 높이로 |

자세 유지: **이 장면만** 또는 **이전부터**(바로 앞 장면 시작 ~ 이 장면 끝).

## 공

- 높이 밴드: 자동 / 하단 / 상단 / 공중
- 다음 장면으로의 비행: 보통 / 빠른 공 / 느린 공 / 스파이크
- 스파이크는 더 빠르고 궤적이 평평. 하단에서는 고를 수 없음
- 3D에서 리시브 선수와 가까우면 공을 팔 플랫폼에 맞춤

## 내보내기

- 캡처(PNG), GIF, 영상. 3D 보기 중이면 3D로 찍힘
- 갤러리에 남김. **백업 `.vpb`에는 미디어가 들어가지 않음**

## 대형 프리셋 (기본)

5-1 로테이션 R1~R6, 6-2, 리시브 W, 서브 1/중앙/5번, 오버랩, 파이프, 퀵, 텐덤.

에디터에서 불러오거나, 홈에서 대형 프리셋 편집기로 직접 만들 수 있다.

## 경기 기록

- 세트·랠리 점수, 서브권, 로테이션
- 타임아웃, 교체, 리베로
- 선수 명단은 전술과 별도. 백업에 포함

## 3D 보기 한계

- 연속 모션(걷기·점프 물리)은 없음. 장면마다 자세 메시를 갈아끼움
- 위치 수정은 2D 전술모드에서 하는 것이 기본. 3D에서도 드래그는 된다
- 아직 없는 모델: 대기, 토스, 블로킹. 자세한 목록은 [3d-player-pose-plan.md](./3d-player-pose-plan.md)
