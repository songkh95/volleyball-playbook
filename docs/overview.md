# 이 앱이 뭔가

**배구 전술 보드**는 배구 코치·선수가 코트 위에서 전술을 그리고, 컷(장면)을 이어 재생하는 도구다.

로그인과 서버가 없다. 전술은 그 기기 브라우저(또는 앱) 안의 IndexedDB에만 남는다. PC 웹과 폰 앱은 **같은 코드**를 쓰지만, 클라우드로 실시간 동기화하지 않는다. 옮기려면 `.vpb` 백업 파일을 저장하고 다른 기기에서 불러온다.

## 한 줄로

컷을 여러 장 만들고 → 선수·공을 배치하고 → 재생하면 움직임이 이어진다. 3D 보기에서는 같은 장면을 사람 피규어로 볼 수 있다.

## 대상

- 배구 팀 전술을 칠판 대신 폰·PC에 남기고 싶은 사람
- 리시브 대형, 공격 조합, 블로킹 위치를 장면으로 보여주고 싶은 코치

## 하지 않는 것

- 계정, 소셜 로그인, 클라우드 동기화
- 실시간 멀티플레이어 편집
- 풀 애니메이션(걷기·착지·팔로스루). 3D는 **정지 자세를 갈아끼우는** 방식
- FIVB 로고·실존 선수 초상

## 어떻게 돌아가나

```
홈 (전술 프로젝트)
  └─ 앨범 안의 전술 카드
       └─ 에디터
            ├─ 전술모드 (2D 코트, 원형 마커)
            ├─ 영역 (책임 범위·낙하 부채)
            ├─ 3D 보기 (피규어 + 공 궤적)
            └─ 마킹모드 (펜·지우개·레이저)
```

하단 탭은 **홈 / 갤러리 / 기록**이다.

- **홈**: 전술 프로젝트(앨범)와 대형 프리셋
- **갤러리**: 에디터에서 찍은 캡처·GIF (백업 파일에는 안 들어감)
- **기록**: 경기 스코어·로테이션·교체 (백업 파일에 함께 저장)

## 기술 한 줄

Vite + React + TypeScript. 2D는 HTML Canvas, 3D는 Three.js. 네이티브는 Capacitor(안드로이드). 웹은 GitHub Pages.

로컬 개발: `npm run dev` → `http://localhost:5173/`
