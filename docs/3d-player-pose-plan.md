# 3D 선수 자세 계획서

장난감 피규어처럼 **정지 자세만** 갈아끼운다.  
연속 애니메이션, 걷기, 점프 물리, 착지 모션은 만들지 않는다.

2D 전술모드는 지금처럼 원형 마커.  
사람 모델은 **3D 보기 전용**.

앱 전체 설명은 [README.md](./README.md)부터.

---

## 현재 상태 (2026-09)

자세는 공 높이로 자동 고르지 않는다. **선수 편집에서 수동**으로 고른다.

| 파일 | 자세 | 상태 |
|---|---|---|
| `player-receive.glb` | 리시브 | 있음. 공이 가까우면 손 플랫폼 위로 |
| `player-spike.glb` | 스파이크 | 있음. 타격 컷에서 손 높이 |
| `player-set.glb` | 토스 | **없음** · 1차에 필요 |
| `player-idle.glb` | 대기 | **없음** · 1차에 필요. 지금은 원기둥 |
| `player-block.glb` | 블로킹 | 없음 · 2차. 자세 타입에도 아직 없음 |
| 서브 | — | 장면 이름·포메이션용. 3D 자세 아님 |

아래 4절 “자세를 고르는 규칙”은 **처음 계획**이다. 구현은 수동 선택 + 리시브/스파이크 공 위치 맞춤으로 바뀌었다.

## 1. 목표

- 원기둥 선수를 로우폴리 사람 피규어로 교체
- 그 컷에서 공을 받는 선수만 동작 자세
- 나머지 선수는 기본 스탠스
- 유니폼 색은 기존 선수 색(빨강/파랑/리베로 흰색)을 그대로 사용

## 2. 하지 않는 것

- 프레임 보간 애니메이션
- 런 / 슬라이딩 / 팔로스루
- 남녀·체형·얼굴 종류
- 손가락 리깅
- 2D용 사람 스프라이트

---

## 3. 자세 목록

### 1차 (필수 4개)

| 파일 이름 | 자세 | 언제 쓰나 |
|---|---|---|
| `player-idle.glb` | 대기 / 기본 스탠스 | 공이 이 선수에게 안 옴 |
| `player-receive.glb` | 리시브 / 디그 | 하단 + 보통/느린/빠른 |
| `player-set.glb` | 토스 / 오버핸드 | 상단 + 보통/느린/빠른 |
| `player-spike.glb` | 점프 스파이크 | 상단 + 스파이크 |

### 2차 (있으면 좋음)

| 파일 이름 | 자세 | 언제 쓰나 |
|---|---|---|
| `player-block.glb` | 블로킹 | 네트 앞 + 공중/상단 + 상대 공격 쪽 |

### 3차 (나중)

| 파일 이름 | 자세 | 언제 쓰나 |
|---|---|---|
| `player-jump-set.glb` | 점프 토스 | 세터 + 상단 + (점프토스 옵션) |
| `player-under-set.glb` | 언더hand 토스 | 세터 포지션 + 하단 |

리시브는 **한 종류만**. 넘어질 듯한 디그는 나중에.

언더hand 토스는 공 옵션이 아니라 **선수 클릭 → 포지션(세터) 선택** 후에 하단이면 이 자세를 쓴다.

---

## 4. 자세를 고르는 규칙

공이 도착하는 **그 컷**만 본다.

1. 공과 가까운 선수 1명만 동작 자세. 나머지는 idle.
2. 하단 + (보통/느린/빠른) → receive
3. 상단 + (보통/느린/빠른) → set
4. 상단 + 스파이크 → spike
5. 하단 + 스파이크는 막는다. 스파이크는 상단일 때만 고를 수 있음
6. 공중이고 선수와 멀면 → 전원 idle
7. 블로킹은 2차. 그때는 “네트 앞 + 상대 공격” 조건을 따로 정함
8. 컷과 컷 사이에 자세를 섞지 않는다. 도착 컷 자세로 바로 교체

스파이크 공은 빠른 공보다 더 빠르고, 궤적은 더 평평하게.

## 5. 단계

### 0단계 — 에셋 규격 확정 (지금)
당신이 모델 4개를 규격에 맞춰 만든다.  
앱 코드는 아직 안 바꾼다.

### 1단계 — 사람 교체 (idle만)
- 3D 원기둥 → `player-idle.glb`
- 위치, 라벨, 유니폼 색만 연결
- 전술 기능은 그대로

완료 기준: 3D 보기에서 선수 6명이 피규어로 보이고, 색·이름이 맞음.

### 2단계 — 공 옵션에 스파이크 추가
- 이동: 보통 / 빠른 공 / 느린 공 / **스파이크**
- 상단이 아니면 스파이크 비활성
- 궤적: 더 빠르고 평평
- 이 단계까지는 원기둥/idle 피규어여도 됨

완료 기준: 전술모드에서 스파이크를 고르고, 3D에서 공이 빠르게 평평하게 감.

### 3단계 — 자세 4종 연결
- idle / receive / set / spike
- 규칙 4번대로 자동 선택
- 공 맞는 위치에 `ball_contact` 마커가 있으면 공 높이를 거기에 맞춤

완료 기준: 하단 리시브, 상단 토스, 상단+스파이크 타격 자세가 컷마다 바뀜.

### 4단계 — 블로킹
- `player-block.glb`
- 네트 앞 조건이 맞을 때만

### 5단계 — 포지션과 나중 자세
- 선수 클릭 시 포지션 선택 (S, OH, MB, OP, L 등)
- 세터 + 하단 → under-set
- 점프 토스는 그 다음

한 단계가 끝나야 다음 단계로 간다.

## 6. 당신이 만들어서 줘야 하는 것

코드를 짜기 전에, 아래를 **당신이 만듭니다.**  
나는 모델 조각·리깅·포즈 작업을 대신하지 않고, 받은 GLB를 앱에 끼웁니다.

### 지금 당장 (0~3단계)

같은 몸, 같은 장난감 스타일로 **정지 GLB 4개**:

1. `player-idle.glb`
2. `player-receive.glb`
3. `player-set.glb`
4. `player-spike.glb`

블렌더/매직에바토/노멀로 만들어도 된다. 중요한 건 **4개가 같은 인형**처럼 보이는 것이다.

### 나중에

5. `player-block.glb`
6. `player-jump-set.glb`
7. `player-under-set.glb`

### 모델 규격 (반드시 지킬 것)

- 형식: **GLB** (glTF 바이너리)
- 축: **Y-up**, 서 있는 바닥이 **Y = 0** (발바닥이 원점)
- 키: 약 **1.80~1.85m** (앱 선수 키와 맞춤)
- 바라보는 방향: **+Z** (우리 엔드 쪽). 앱에서 공/네트 쪽으로 돌릴 수 있음
- 애니메이션 트랙 **없음**. 메시만
- 한 파일 = 한 자세. 한 GLB 안에 여러 자세를 넣지 말 것
- 삼각형 **5천 개 이하** 권장. 선수가 6~9명이라 무거우면 3D가 버벅임
- 파일 하나 **1MB 이하**, 가능하면 300~600KB

### 색을 입히려고 재질 이름을 이렇게

앱이 선수 색을 입히려면 재질 이름이 고정이어야 한다.

| 재질 이름 | 용도 | 앱이 하는 일 |
|---|---|---|
| `Jersey` | 상의 | 선수 색으로 바꿈 |
| `Shorts` | 바지 | 상의보다 조금 어둡게 |
| `Skin` | 피부 | 그대로 |
| `Hair` | 머리 | 그대로 |
| `Shoes` | 신발 | 그대로 |
| `Accent` | 라인/번호 등 | 그대로 또는 살짝 밝게 |

리베로는 흰색 상의가 되어야 하므로, 상의는 반드시 `Jersey` 재질로 분리.

### 공 위치 마커 (강력히 권장)

각 자세 GLB 안에 빈 오브젝트(Empty)를 하나 넣고 이름을 **`ball_contact`** 로 한다.

- receive: 팔 플랫폼 앞
- set: 머리 위 양손 사이
- spike: 타격하는 손 앞
- idle: 없어도 됨
- block: 손끝 앞 (2차)

있으면 공이 손에 붙고, 없으면 지금처럼 높이(m)만 쓴다.

### 스타일

- 오래된 필통 속 장난감: 매끈한 로우폴리, 큰 머리 가능, 사실적인 근육/옷주름 금지
- 4개 자세가 **같은 비율, 같은 얼굴, 같은 유니폼 형태**
- 스파이크만 점프 자세라 발이 떨어져 있어도 됨. 그때는 발 아래가 아니라 **착지 예정이 원점**이 아니라, **발(또는 가장 낮은 점)을 Y=0에 두지 말고** 점프 높이가 보이게 발바닥을 대략 **0.4~0.7m** 에 두거나, `ball_contact`만 정확히 두고 발 높이는 메모로 알려 주기

스파이크 점프 높이를 파일 안에 넣기 애매하면, 줄 때 한 줄만 적어 주면 된다.  
예: `spike 발바닥 Y=0.55m, ball_contact Y=2.6m`

### 주지 않아도 되는 것

- FBX, OBJ, Blend 원본 (있으면 보관만)
- 텍스처 4K
- Mixamo 전체 모션 클립
- 좌우 타격용 모델 두 벌 (앱에서 뒤집음)
- 2D 그림

### 전달 방법

프로젝트에 이 폴더로 넣어 주면 된다.

```
public/models/player-idle.glb
public/models/player-receive.glb
public/models/player-set.glb
public/models/player-spike.glb
```

또는 채팅에 파일로 주면 내가 그 위치로 옮긴다.

4개를 한 번에 못 만들면 **idle만 먼저** 줘도 1단계는 시작할 수 있다.

## 7. 내가 코딩으로 하는 것

- GLB 로드, 색 입히기, 라벨
- 높이×이동 → 자세 선택
- 스파이크 공 옵션과 평평한 궤적
- 상단이 아닐 때 스파이크 선택 막기
- 좌우 반전, 공을 받는 쪽을 바라보게 회전
- 나중: 선수 포지션 선택, 블로킹/언더토스 규칙

## 8. 다음 액션

1. 당신이 idle / receive / set / spike GLB를 규격대로 제작
2. idle이 준비되면 **1단계 코딩** 시작
3. 스파이크 옵션은 모델과 별개로 **2단계**에서 바로 넣을 수도 있음

모델 없이 2단계(스파이크 공 옵션)만 먼저 코딩할지는 당신이 정하면 된다.
