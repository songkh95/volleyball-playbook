0. 한 줄 요약
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

모바일 웹(Vite + React)을 먼저 만들고 Capacitor로 스토어에 올린다.
데이터는 기기의 IndexedDB에 두고, 앱 삭제 전 백업 파일(.vpb)을 폰에 저장한다.
재설치·컴퓨터 웹에서는 그 파일을 불러온다. 서버비 0원.

웹과 앱은 실시간 동기화가 아니다.
PC에서 고치면 파일을 다시 저장한 뒤 폰에서 불러와야 한다.

1. 비용
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 서버 / DB / 로그인 / SMS: 없음 (사용자 1명이든 10만이든 0원)
- 스토어: Google Play $25 1회 + Apple Developer 연 $99 (감수)
- PC 웹 호스팅: Cloudflare Pages 등 정적 호스팅 (코드만 올림, 사용자 파일은 올리지 않음)
- iOS 제출: Mac + Xcode 필수 (Windows에서는 안드로이드·웹만 가능)

영상이 클라우드에 들어가면 단가가 무너진다.
전술 JSON만 백업하고, 캡처·영상은 기기에만 둔다.

2. 백업 파일 (폰 + 웹)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

iOS·안드로이드는 앱 삭제 순간을 가로챌 수 없다.
삭제 버튼을 누를 때 자동 팝업은 불가능하다.
UX는 “삭제하기 전에 백업 저장”이다.

순서
1) 앱에서 [백업 저장] → 파일 앱 / 다운로드 / 드라이브
   → 폰에 playbook-날짜.vpb 가 남음
2) 앱 삭제 → 앱 안 데이터는 사라짐. 파일은 그대로
3) 재설치 → [백업 불러오기] → 그 파일 선택 → 홈 전술 목록 복구
4) 파일을 PC로 옮긴 뒤 웹앱에서 [백업 열기]
   → 같은 전술을 컴퓨터 브라우저에서 재생·수정

주의: .vpb를 더블클릭만 해서는 웹이 자동으로 켜지지 않는다.
컴퓨터에서는 웹앱 주소에 접속한 다음 [백업 열기]로 파일을 고른다.
파일은 서버로 업로드되지 않고, 브라우저가 PC 안에서만 읽는다.

파일 종류
- 전체 백업 .vpb : 전술 전부 (앱 삭제 전, PC 이동)
- 전술 하나 .vplay : 선수에게 카카오·에어드롭

백업에는 갤러리(캡처·영상)를 넣지 않는다. (용량·실패 방지)
전술 JSON만 복구되면 다시 캡처할 수 있다.

불러오기: “현재 목록에 추가”와 “전부 교체” 둘 다 제공한다.
덮어쓰기만 있으면 실수로 기존 전술이 날아간다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

0 · 뼈대 (이번 주)
    Vite, 다크 셸, 홈/갤러리/에디터, IndexedDB
    완료: 새로고침해도 홈에 제목 카드가 남음
    + 주황 코트가 에디터를 가득 채움 (1:2, 프리존 없음)

1 · 코트 + 오브젝트
    하프코트, 공+선수 드래그, 선수 편집 모달
    완료: 이름·유니폼 색 바꾸고 드래그

2 · 컷 + 보간
    컷 추가/삭제, 슬라이더, 재생, 점선 궤적
    완료: Cut 1→3 스크럽이 끊기지 않음

3 · 도구 + 프리셋
    화살표 펜, 실행 취소, 이전 컷 복사, 1번 컷 리셋, 구역
    대형 3종: W리시브, 5-1 서브리시브, 기본 블로킹
    완료: 펜을 떼면 화살촉

4 · 백업 파일
    [백업 저장] [백업 불러오기], 삭제 전 안내
    완료: 폰에서 저장한 .vpb를 웹에서 열면 같은 전술

5 · 미디어 + 갤러리
    PNG 캡처, 전술 제목 폴더 (클라우드 X)
    완료: 캡처가 해당 전술 폴더에 보임

6 · 스토어 + 웹 주소
    Capacitor, 오버스크롤 차단, 커스텀 모달
    완료: 갤럭시 내부테스트 + TestFlight + PC에서 파일 열기

7. 데이터 모델 (백업 파일 = 이 타입)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

좌표는 코트 기준 0~1.
하프/풀 전환 시 타임라인은 초기화(경고 모달 후).
보간은 인접 컷의 x,y 선형 보간.
선수 id는 전 컷 공통. 펜 선은 그 컷에만, 보간 없음.

Backup { schema: 1, app: "volleyball-playbook", exportedAt, plays: Play[] }
Play   { id, title, court: half|full, rosterSize: 6|9, cuts: Cut[], updatedAt }
Cut    { id, durationMs: 1000, objects: Obj[], strokes: Stroke[] }
Obj    { id, kind: player|ball, x, y, label, color }
Stroke { points[], color, arrowhead: true }

13. 원기획 핵심 기능 (상세)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

컷 기반 애니메이션
- 하단 타임라인: Cut 1, 2, 3… 버튼 + 스크러버
- [+] 컷 추가, [삭제] 현재 컷 삭제 (최소 1개)
- 컷 버튼 길게 눌러 드래그해 순서 변경
- 슬라이더 드래그 시 선수·공 실시간 보간
- [재생] 시 컷 순서대로 애니메이션, 현재 컷 버튼 하이라이트
- 이동 궤적: 선수 흰색 점선 화살표, 공 노란색 점선 화살표

코트
- 프리존 없이 주황 플레이 코트, 화면 가득 (풀코트 1:2)
- 하프코트(기본): 우리 팀 전체 + 상대 어택 라인 (네트 앞 블로킹)
- 풀코트: 18m x 9m
- 구역 오버레이: 표시 안함 / 6구역 / 9구역 (하단 코트, 반투명 흰 번호)

오브젝트
- 공 1개, 선수 터치 드래그
- [선수 추가] 무제한
- 탭하면 모달: 이름/포지션 라벨, 유니폼 색 (우리 레드, 상대 블루, 리베로 화이트 등)

그리기
- 스마트 화살표 펜: 손을 떼면 끝에 화살촉
- 실행 취소 1단계
- 이전 컷 복사 (선수/공 위치 덮어쓰기)
- 첫 컷 리셋

대시보드
- 상단 탭 [홈] [갤러리]
- 홈: 썸네일+제목, 점선 + 카드로 새 전술
- 새 전술 모달: 제목, 하프/풀, 6인/9인
- window.alert / confirm 금지, 커스텀 모달만
